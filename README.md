# Giums — Portfolio

Site estático com os arquivos de GIUMS SITE.

## Render

- Tipo: Static Site
- Repositório: Biieru/GIUMS-SITE
- Branch: main
- Root Directory: vazio
- Build Command: `echo "Static site ready"`
- Publish Directory: `.`

Também é possível usar New → Blueprint com o arquivo render.yaml.

## Conteúdo

HTML, CSS e JavaScript sem dependências de build. O dragão da abertura e a foto estão em assets/. A galeria em js/data.js e os quadros de YATHRA em index.html ainda contêm placeholders.
